# Kushagra & Roshani — Wedding Invitation

A responsive, bilingual (English/Hindi) static invitation website with gentle reveal animations, falling petals, low-volume looping music, an event schedule, live countdown, venue links, and the original invitation-card gallery.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder, including the `assets` and `.github` folders.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions** as the source.
5. Push to the `main` branch. The included workflow will publish the site automatically.

The site is plain HTML, CSS, and JavaScript and needs no build step.
